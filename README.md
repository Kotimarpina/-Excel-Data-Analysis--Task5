# Task 5 – Excel Data Analysis

## 📌 Overview

This project is completed as part of the **Veda Technologies Data Analytics Internship – Task 5: Excel Data Analysis**.

For this task, I worked with a **Retail Sales dataset** and used Microsoft Excel to analyze sales and profit performance across different regions and product categories.

The main focus of the task was to become comfortable with analyzing a structured dataset using Excel's core analytical features, especially **PivotTables, sorting, filtering, formulas, and summary analysis**.

## 🎯 Objective

The objective of this task was to analyze retail sales data and answer different business-related questions using Excel.

The analysis focuses on:

- Understanding sales performance across regions
- Comparing sales across product categories
- Analyzing profit by category
- Analyzing profit by region
- Comparing overall sales and profit

## 🛠️ Tools Used

- Microsoft Excel
- PivotTables
- Excel Formulas
- Sorting and Filtering
- Basic KPI Analysis

## 📊 Dataset

**Dataset:** Retail Sales Dataset

The dataset contains retail sales information that can be analyzed across different business dimensions such as region, category, sales, and profit.

## 📈 PivotTables Created

### 1. Sum of Sales by Region

This PivotTable analyzes the total sales generated across different regions.

**Business Question:**
> Which regions contribute the most to overall sales?

This helps compare regional sales performance and identify differences between regions.

---

### 2. Sum of Sales by Category

This PivotTable compares total sales across different product categories.

**Business Question:**
> Which product categories generate the highest sales?

This provides an overview of category-level sales contribution.

---

### 3. Profit by Category

This analysis compares profit generated by different product categories.

**Business Question:**
> Which categories contribute more to overall profitability?

Sales alone do not always represent business performance, so analyzing profit provides an additional perspective.

---

### 4. Profit by Region

This PivotTable analyzes profit performance across different regions.

**Business Question:**
> Which regions generate higher profits?

The analysis helps compare regional profitability rather than looking only at sales volume.

---

### 5. Sum of Sales and Profit

This PivotTable provides a combined view of sales and profit.

**Business Question:**
> How do sales and profit compare across the dataset?

Comparing these two metrics helps provide a broader view of overall business performance.
